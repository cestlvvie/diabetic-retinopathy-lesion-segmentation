# Diabetic Retinopathy Lesion Segmentation

Multi-label segmentation of diabetic retinopathy lesions from retinal
fundus images using deep learning.

The project segments four lesion types:

- Microaneurysms
- Hemorrhages
- Hard exudates
- Soft exudates

## Dataset

This project uses the Indian Diabetic Retinopathy Image Dataset
(IDRiD). The dataset contains expert-provided pixel-level lesion
annotations.

The dataset is not distributed in this repository. It must be
downloaded separately from the official IDRiD page.
